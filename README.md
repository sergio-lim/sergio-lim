## Featured projects

| Project | What it is |
|---|---|
| [**ai-job-hunter**](https://github.com/sergio-lim/ai-job-hunter) | A **keyless job-hunting pipeline**: collect from public boards, dedupe, verify every link, score the fit against a profile, and classify recruiter replies (regex with an optional LLM hook). Runs offline in demo mode, with an animated CLI demo and a daily GitHub Action. |
| [**ai-decision-engine**](https://github.com/sergio-lim/ai-decision-engine) | Give your agents **typed decisions** instead of parsing LLM text. A decision-model layer (Jev / TypeSafe) with confidence-gated routing, plus a regex baseline benchmark (100% vs 75% accuracy). |
| [**agent-long-term-memory**](https://github.com/sergio-lim/agent-long-term-memory) | Your agent wakes up with amnesia. A dependency-free **long-term memory** with provenance, offline BM25 retrieval and a compiled wiki with backlinks. |
| [**prompt-injection-lab**](https://github.com/sergio-lim/prompt-injection-lab) | Your agent reads the internet; the internet reads your agent's instructions. An **offline, reproducible lab** on prompt injection against tool-using agents, with defenses and a success-rate matrix. |
| [**skill-demand-radar**](https://github.com/sergio-lim/skill-demand-radar) | What skills does the market actually want? A daily **keyless job-market radar** with a static dashboard, auto-updated by GitHub Actions. |

All five run offline or with a single env var, with no pip dependencies.
